description: Genera varias variantes de diseño en paralelo para comparar y elegir
argument-hint: <componente/pantalla> [nº de variantes, default 4]
---

Usá la skill **ui-ultimate-reforce** con el método de exploración de `references/taste.md`
(estilo superdesign): explorar antes de comprometerse.

Qué explorar: $ARGUMENTS

1. Generá 3–5 variantes del mismo componente/pantalla en **HTML/artefacto desechable**, con
   la **misma data real** en todas. Cada variante cambia **una** dimensión: el arquetipo de
   estilo, la densidad, la escala tipográfica, o el nivel de movimiento.
2. Presentalas para comparar lado a lado, con una línea que diga qué explora cada una.
3. Cuando el usuario elija, **bifurcá la ganadora** y refinala; descartá el resto. No
   promedies variantes.
4. Recién ahí integrá al proyecto real con sus tokens y componentes, pasando las tres puertas.

Barato en tokens: HTML plano, sin instalar nada.
